# СЕЙЧАС — мировой обзор

Свежий старт проекта: адаптивное редакционное издание без рекламных блоков и тяжёлых библиотек. Главная, страница новости, страница «О проекте» и экран 404. Ошибка 404 показывает предоставленное изображение.

## Запуск

Требуется Node.js 18+. В папке проекта:

```bash
npx wrangler pages dev .
```

Откройте адрес, который покажет Wrangler. Используйте Wrangler для локального просмотра маршрутов и Pages Functions.

## Публикация на Cloudflare Pages

Проект настроен для Cloudflare Pages в `wrangler.toml`: имя проекта `seychas-world-news`, команда сборки не нужна, каталог вывода — `.`. Папка `functions/` должна попасть в публикацию: в ней работает серверная проверка страны.

### Публикация через GitHub

1. Создайте GitHub-репозиторий и загрузите в него файлы проекта из корневой папки. Не загружайте `.wrangler/`, `.dev.vars` или файлы `.env`.
2. Войдите в Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** и разрешите доступ к нужному GitHub-репозиторию.
3. Выберите этот репозиторий. Для статического проекта оставьте Build command пустой, Build output directory укажите `.`. Если Cloudflare предлагает настройки из `wrangler.toml`, используйте их.
4. Нажмите **Save and Deploy**. После публикации откройте выданный адрес `*.pages.dev`.
5. Убедитесь, что в опубликованной версии ответ для IP из Кыргызстана — HTTP 403 с изображением, а при VPN с IP другой страны открывается сайт.

Если проект уже находится в Git, отправьте файлы в GitHub обычным `git push`; Cloudflare Pages будет автоматически публиковать новые изменения после привязки репозитория.

### Админ-панель и база новостей

Админ-панель находится по адресу `/admin.html`. Она позволяет просматривать, добавлять, редактировать и удалять новости; данные сохраняются в Cloudflare D1 и сразу попадают в публичную ленту. При первом входе панель заполняет пустую базу десятью демонстрационными новостями. Если база не подключена, сайт продолжает показывать демо-ленту.

После создания Pages-проекта настройте базу и пароль:

1. Создайте D1 базу: `npx wrangler d1 create seychas-news`.
2. Примените схему: `npx wrangler d1 migrations apply seychas-news --remote`.
3. В Cloudflare Dashboard откройте Pages-проект → **Settings → Bindings → Add → D1 database binding**. Имя переменной укажите `NEWS_DB`, выберите базу `seychas-news`, сохраните и заново разверните проект.
4. В **Settings → Variables and Secrets** добавьте зашифрованный секрет `NEWS_ADMIN_PASSWORD` с длинным уникальным паролем. Сохраните и заново разверните проект.
5. Откройте `https://<имя-проекта>.pages.dev/admin.html` и войдите с этим паролем.

Для локальной проверки пароль можно задать в игнорируемом Git файле `.dev.vars`, а D1 binding подключить командой Wrangler `--d1 NEWS_DB=<database-id>`. Не добавляйте `.dev.vars` или рабочий пароль в GitHub.

## Геоблокировка

Важно: проверка IP работает только после публикации на Cloudflare Pages с включёнными Pages Functions. Если открыть сайт через Live Server, `file://` или обычный статический хостинг, серверный middleware не запускается — настройте Cloudflare Pages и опубликуйте папку проекта вместе с `functions/`.

`functions/_middleware.js` проверяет страну на сервере до ответа любого маршрута. Для кода `KG` возвращается HTTP 403 с одной HTML-страницей. Изображение встроено в неё, поэтому не требуется отдельный запрос к статическому файлу. Для блокировки других стран измените список `BLOCKED_COUNTRIES = ["KG"]`, например на `["KG", "RU"]`. Чтобы отключить блокировку, задайте пустой список.

## Новости и окружение

`/api/news` возвращает сохранённые в D1 новости, а если база пуста или не подключена — 10 демонстрационных коротких обзоров. Админ-панель использует переменные `NEWS_DB` (D1 binding) и секрет `NEWS_ADMIN_PASSWORD`. Внешний API-ключ пока не требуется.

migrations/                схема базы Cloudflare D1
assets/oshibki-sajta.jpg   пользовательское изображение 404
